# Rock-Paper-Scissors
A classic Rock Paper Scissors game built using HTML, CSS, and JavaScript with interactive gameplay and score tracking.

## Features
- Interactive gameplay
- Player vs. computer
- Random computer choices
- Score tracking
- Game result display

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Play
1. Choose Rock, Paper, or Scissors.
2. The computer randomly selects its move.
3. Rock beats Scissors.
4. Scissors beats Paper.
5. Paper beats Rock.
6. The winner is displayed after each round.

## How to Run
Open `index.html` in your browser.
